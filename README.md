# Student Registration System — CI/CD

A two-tier web application built with Python Flask and MySQL.

## Technology Stack

- Python and Flask
- MySQL
- Git and GitHub
- Docker and Docker Compose
- Jenkins
- AWS EC2
- Pytest

## Planned Features

- Register students
- View registered students
- Validate input and handle duplicate emails
- Persist student records in MySQL
- Run automated tests
- Build and deploy through Jenkins CI/CD

## Architecture

Developer → GitHub → Jenkins → Docker Compose
→ Flask Application → MySQL Database
